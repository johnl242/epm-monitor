Core Features

Everything You Need to Monitor Productivity

A lightweight Windows agent silently tracks work patterns and syncs to your cloud dashboard in real time.

📊

App Usage Tracking

Tracks every application your employees use — browser, Excel, Slack, custom tools — with precise time-on-app metrics.

⏱️

Active vs Idle Time

Automatically detects mouse and keyboard activity to separate productive time from idle periods throughout the day.

📸

Periodic Screenshots

Captures screenshots at configurable intervals (default 30s). Stored securely, accessible only to authorized managers.

☁️

Real-time Cloud Sync

All activity data syncs to Supabase cloud automatically. View live reports from anywhere without touching the employee's machine.

🔒

Uninstall Protection

Password-protected removal. Registry persistence ensures the agent survives reboot and cannot be disabled without authorization.

📋

Detailed Activity Logs

Complete timeline of window focus events, app switches, and session data. Export to CSV or view in the web dashboard.

🔑

License Key Enforcement

Per-seat licensing enforced at the server. Each machine registers against your company license. Seats are tracked in real time.

📈

Web Dashboard

Manager portal to view all computers, activity timelines, productivity scores, and generate company-wide or per-employee reports.

🏢

Multi-Tenant Architecture

Each company gets a fully isolated environment. Data is segregated at the database level — one company can never see another's data.
